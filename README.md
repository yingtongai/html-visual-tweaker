# HTML Visual Tweaker

一个基于 Chrome Manifest V3 的本地 HTML 可视化微调扩展。可以在浏览器中直接选中页面元素，实时调整文案、文字样式、位置与尺寸，并按页面地址保存最近 5 个版本。

> “保存修改”和“恢复”只更新浏览器中的版本记录，不会创建或改写文件；只有点击“导出副本”或“覆盖原文件”，才会生成新文件夹或覆盖你确认的源 HTML。

## 功能

- 仅在本地 `file://` HTML 页面启用，避免影响普通网站。
- 点击“修改”后进入编辑状态；保存后自动锁定，防止误改。
- 点击“保存修改”只保存浏览器历史，每个页面保留最近 5 个版本。
- 工具栏会根据当前状态精简显示；恢复历史和隐藏入口收在“更多”菜单中。
- 工具栏和属性面板作为一组联动浮层，可按住任一标题整体拖动；首次打开时会自动避开当前选中的元素。
- 编辑过程中可撤销和恢复，支持 `Ctrl+Z`、`Ctrl+Shift+Z` 和 `Ctrl+Y`。
- 选中元素后可用方向键移动；按住 `Shift` 每次移动 10px，按住 `Alt` 则改为调整宽高。
- 文案、图片及每个样式字段只有在本轮发生变化时才显示单项重置；重置会回到点击“修改”之前的值。
- 可在元素之间复制和粘贴视觉样式，支持面板按钮及 `Ctrl+Shift+C/V`；不会覆盖文案、图片和位置。
- 工具栏提供“导出副本”和“覆盖原文件”两个同色按钮，无需经过选择弹窗。
- 覆盖前会校验完整 HTML、缓存原内容并在写入后复核；写入异常时会尝试恢复，避免源文件变空。
- “导出副本”会生成与源文件同名的 HTML，并自动复制页面引用的本地图片、CSS、脚本和字体等资源。
- 重复导出到同一路径时，插件会等待副本内容读取完整并识别文件更新，不会再用旧记录或原图片覆盖新内容。
- 导出文件夹固定为浏览器默认下载目录下的 `HTML Tweaker Exports/当前项目名/`，不再提供无效的路径设置入口。
- “覆盖原文件”会打开浏览器的系统保存窗口；选择当前源 HTML 并确认后，只改写该 HTML，不移动也不改写其他依赖文件。扩展会校验文件名和内容，避免误选其他文件。
- 调整文案、颜色、字体、字号、边距、圆角与位移。
- 可单独选中标题内部的强调文字等行内元素，不会总是跳到外层标题。
- 选中框显示元素标签，四个角可拉伸宽高；移动时提供对齐线和吸附。
- 选中 `<img>` 图片或只包含一张图片的常见图片容器后，可以从本机选择另一张图片替换；替换结果会随版本一起保存。
- “取消”撤销本次未保存调整；“恢复”可回到初始状态或最近 5 个保存版本。
- “隐藏”收起工具栏和选中框；点击 Chrome 扩展图标可再次显示。

## 直接安装

仓库已经包含构建完成、可直接加载的 `dist/` 扩展文件，不需要安装 Node.js。

1. 在 GitHub 页面点击 **Code**，选择 **Download ZIP**。
2. 解压下载的 ZIP 文件。
3. 打开 Chrome 的 `chrome://extensions`，开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压目录中的 `dist` 文件夹。
6. 在扩展卡片中打开“详情”，开启“允许访问文件网址”。
7. 用 Chrome 打开本地 HTML 文件，例如 `file:///E:/example/index.html`。
8. 点击浏览器工具栏中的 **HTML Visual Tweaker** 图标，工具栏会显示在页面右上角。

## 使用方法

1. 点击工具栏的“修改”。
2. 点击要调整的元素。优先点击文字、图标或图片本身，可以从已选容器切换到内部的小元素。
3. 直接拖动元素移动位置；靠近其他元素的边缘或中心时会出现对齐线并吸附。
4. 拖动选中框四角调整宽度和高度；也可在右侧面板输入精确值。
5. 在“文案”输入框修改文字，或调整颜色、字体、字号、外边距、圆角和位移。
6. 选中图片时，点击右侧面板中的“替换”，从本机选择新图片。
7. 需要精调时使用方向键移动，`Shift + 方向键`每次移动 10px，`Alt + 方向键`调整尺寸；工具栏可撤销或恢复。
8. 只有本轮改过的项目才会显示“↺”；点击后只把该项恢复到进入编辑前，元素标题旁可复制或粘贴样式。
9. 点击“保存修改”保存当前版本。此操作只写入浏览器存储，不下载文件。
10. 如需生成独立副本，点击“导出副本”。扩展会在 `下载/HTML Tweaker Exports/当前项目名/` 生成完整文件夹；其中包含同名 HTML，并按原相对目录复制可识别的本地依赖。
11. 如需直接更新当前文件，点击“覆盖原文件”，在系统保存窗口中选中当前页面的源 HTML 并确认覆盖。此方式只需改写 HTML，因为页面原有的 CSS、图片、脚本等仍在原位置。
12. 点击“取消”放弃本次未保存调整；使用“恢复”回到初始状态或任一已保存版本，这两项不会生成或改写文件。

## 数据与限制

- 输出页面的修改保存在 HTML 文件的 `HTML_VISUAL_TWEAKER` 托管区块；即使隐藏、退出或卸载扩展，输出版本仍会显示修改结果。
- 导出位置固定在浏览器默认下载目录下，由当前 HTML 所在文件夹名称自动生成项目子目录。
- 扩展会递归查找 HTML、CSS 和模块脚本里明确引用的本地资源并一并导出；在线 CDN 资源仍保持在线地址，脚本运行时动态拼接出来的文件地址可能无法自动识别，导出完成提示会显示未能复制的资源数量。
- 历史版本保存在浏览器本地 `chrome.storage.local`，按本地页面 URL 区分，不会上传网络；只有主动点击“覆盖原文件”并在系统窗口确认时才会写回源 HTML，扩展不会改写源 CSS。
- 每个页面只保留最近 5 个已保存版本。
- 首版只调整元素的外层样式；不会编辑图表数据、Canvas/SVG 内部对象、跨域 iframe 或 Shadow DOM 内部节点。
- 伪元素（`::before` / `::after`）没有独立 DOM 节点，暂不能单独选中。

## 开发与更新构建

只有修改源码时才需要 Node.js 18+：

```bash
npm install
npm run typecheck
npm run build
```

每次发布源码修改时，请把重新生成的 `dist/` 一起上传。安装过扩展的用户可在 `chrome://extensions` 点击“重新加载”，再刷新目标页面。
